# Enterprise Security Platform

A comprehensive security platform providing infrastructure-as-code, secrets management, container orchestration, and monitoring capabilities for enterprise environments.

## Directory Structure

- **architecture/**: Architecture documentation and design decisions
- **terraform/**: Infrastructure as Code (IaC) using Terraform
- **vault/**: HashiCorp Vault configuration for secrets management
- **kubernetes/**: Kubernetes deployment configurations
- **k8s/**: Kubernetes and Minikube development configurations
- **pki/**: Public Key Infrastructure setup and management
- **python/**: Python-based security services and utilities
- **monitoring/**: Monitoring, logging, and alerting configurations
- **disaster-recovery/**: Business continuity and disaster recovery plans

## Getting Started

1. Review the [architecture/architecture.md](architecture/architecture.md) for platform overview
2. Check the [architecture/threat-model.md](architecture/threat-model.md) for security considerations
